# Portfolio scope

This repository demonstrates an automation architecture pattern rather than a production deployment for a specific client.

It is appropriate evidence for discussing:

- API-first automation design;
- RPA as one execution channel inside a broader solution;
- durable request state and auditability;
- asynchronous processing;
- idempotency and retry strategy;
- dead-letter handling;
- basic observability boundaries;
- containerized local execution and CI;
- architectural trade-offs and production evolution.

It should not be represented as evidence of operating this exact platform at production scale, managing a distributed broker in production, or deploying an LLM feature that is not implemented here.
